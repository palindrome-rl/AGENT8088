Build a Kanban-style team board for a small team, like a simple Trello or Jira board, as a single static web page that works offline (just open index.html or serve the folder, no backend). It should have four columns, To Do, In Progress, In Review and Done. Users should be able to add, edit, delete and move cards between the columns, and every card has a title, an assignee, a priority, an optional due date and a checklist of small steps. They should also be able to search cards by title and filter by assignee.

The team has some rules and they are all written down in rules.md, please read it carefully and make the board follow them, including the limit per person, the checklist rule for Done and the overdue review label with the Advance day button. The board should keep its data between visits, so it should still be there after a reload, and users should be able to export the board to a JSON file and import such a file again (the file format is in export_example.json). If an imported file is broken the board must stay exactly as it was. There should also be an Undo button. The starting cards are in seed.json.

Make it look clean and usable. At the end of rules.md there is a list of attributes I need on the page elements, because I am going to test the board with a script, so please add those. When you are done, tell me what works, what you checked yourself, and anything you could not do.
