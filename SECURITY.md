# Security Policy

## Reporting a vulnerability

Report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/palindrome-rl/AGENT8088/security/advisories/new).
Please do not open a public issue for a suspected vulnerability.

A useful report includes:

- what you found and why it matters
- steps to reproduce it
- the version, branch, or commit you tested

Never include real credentials, API keys, or personal data in a report. If a
reproduction needs a secret, describe it and use a placeholder.

## Scope

Reports are welcome for the agent, its tools and sandboxing, the permission
system, the messaging gateways, the web UI, and the installers.

## Supported versions

Security fixes are made on the current release branch. Please test against the
latest release before reporting.
